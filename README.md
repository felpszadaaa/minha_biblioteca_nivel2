# Minha Biblioteca — Desk App II

Projeto de biblioteca executado pelo terminal. Nesta etapa, os dados ficam na memória enquanto o programa está aberto. Ao fechar o programa, os cadastros e empréstimos são perdidos.

## Como executar

1. Abra o terminal dentro da pasta do projeto.
2. Execute:

```bash
python main.py
```

Não é necessário instalar bibliotecas externas nem configurar banco de dados.

## Funcionalidades

- Cadastrar livros.
- Cadastrar alunos e professores.
- Listar livros e pessoas cadastradas.
- Fazer empréstimos e registrar devoluções.
- Consultar empréstimos ativos e devolvidos.
- Buscar livro pelo código.
- Buscar pessoa pela matrícula.

## Menu

O menu principal apresenta todas as opções e permanece disponível até escolher a opção `0 - Sair`.
